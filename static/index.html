A note before you begin
"The brief is a hypothesis, not a directive. The first thing this system does is interrogate it — five layers down — before any specialist is permitted to start work. Solutioning before interrogation is the most expensive mistake in product strategy."
— From Chapter 3, the Manual
Paste a brief in the left panel — or load one of the three examples — and press Run the Pipeline. The Master Orchestrator will run an intake pass, hand off to seven specialists in sequence, run validation between each, and close with a synthesis.

Each agent corresponds to chapters in the Healthtech Product Strategy Manual. You can click any completed step in the sidebar to inspect its output.
